### [CENA 2 — 0:08 a 0:25] Introdução à Aba

> *(Dashboard aberto. Cursor aponta para a aba "Otimizar".)*

**NARRADOR:**
"No Dashboard, clique na aba **Otimizar**. Esta funcionalidade é ideal para quem já tem um prompt em uso, mas quer melhorá-lo sem reescrevê-lo do zero."

> *(Interface de otimização aparece com dois campos: prompt original e área de resultado.)*

### [CENA 3 — 0:25 a 0:55] Inserindo o Prompt

> *(Cursor clica no campo do prompt original. Animação de digitação do seguinte texto:)*
> *"Escreva uma petição de habeas corpus para soltar meu cliente preso."*

**NARRADOR:**
"Vamos usar um exemplo real. Imagine que você tem este prompt básico para um habeas corpus."

> *(Texto aparece sendo digitado.)*

"*Escreva uma petição de habeas corpus para soltar meu cliente preso.*"

> *(Pausa de 1 segundo. Cursor aponta para o texto.)*

"Este prompt é funcional, mas vago. Ele não especifica o tribunal, o tipo de constrangimento ilegal, os fundamentos jurídicos nem a estrutura esperada do documento. O resultado de qualquer modelo de IA com este prompt seria genérico e provavelmente inutilizável em um processo real."

---

### [CENA 4 — 0:55 a 1:20] Configurando os Focos de Otimização

> *(Cursor aponta para os três checkboxes de foco: Clareza, Completude, Precisão Técnica.)*

**NARRADOR:**
"Antes de otimizar, escolha os **focos de melhoria**. O PromptJur oferece três opções."

> *(Cursor aponta para "Clareza" e o checkbox é marcado.)*

"**Clareza** melhora a estrutura lógica e a objetividade das instruções."

> *(Cursor aponta para "Completude" e o checkbox é marcado.)*

"**Completude** adiciona os elementos que estão faltando — contexto, partes, fundamentos."

> *(Cursor aponta para "Precisão Técnica" e o checkbox é marcado.)*

"**Precisão Técnica** garante que a terminologia jurídica esteja correta e que as referências legais sejam adequadas."

> *(Todos os três checkboxes estão marcados.)*

"Para este exemplo, vamos marcar os três focos para obter a otimização mais completa possível."

---

**NARRADOR:**

"O resultado está pronto."

"O prompt agora define a **persona** do assistente — um advogado penalista experiente."

"Inclui o **contexto do caso** — tipo de constrangimento ilegal, autoridade coatora e fundamento constitucional."

## Indicações Técnicas para Produção

- **Comparação lado a lado:** Usar zoom alternado (esquerda → direita) para destacar as diferenças
- **Prompt original:** Mostrar claramente o texto vago antes de otimizar
- **Prompt otimizado:** Rolar devagar — o espectador precisa ler o conteúdo
- **Melhorias aplicadas:** Destacar cada item com um círculo ou seta ao mencioná-lo
- **Versão salva:** Mostrar o toast de confirmação por pelo menos 2 segundos
